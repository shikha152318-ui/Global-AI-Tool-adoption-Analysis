# Global-AI-Tool-adoption-Analysis
Overview
 This project aims to analyze and visualize global adoption trends of AI tools across countries, industries, company sizes, and demographics. The goal is to identify where adoption is strongest, how fast it’s growing, and which segments are driving engagement. 
 
Objectives
1)Measure AI adoption rates globally.
2)Compare adoption across countries, industries, and company sizes.
3)Track year-over-year growth and daily active user engagement.
4)Build interactive dashboards for visualization in Power BI.

Dataset
The dataset includes 8 key columns:
1)country
2)industry 
3)ai_tool .
4)adoption_rate .
5)year 
6)age_group
